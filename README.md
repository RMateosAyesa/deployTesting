# Optima Dones WebApp

Webapp del proyecto Optima Dones.

## Tech Stack

- React 19.
- TypeScript.
- Vite.
- styled-components.
- Jest + Testing Library.

## Scripts

```bash
npm install    # Instalar dependencias
npm run dev    # Desarrollo
npm run build  # Build producción
npm run lint   # Linting
npm test       # Tests
```

## Requisitos

- Node.js >= 22.18.0
